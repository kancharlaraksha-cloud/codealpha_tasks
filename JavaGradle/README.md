\# Java Application Using Gradle



\## Overview

A simple Java application developed using Gradle as part of the CodeAlpha DevOps Internship.



\## Technologies

\- Java 27

\- Gradle 9.8.1

\- JUnit Jupiter



\## How to Run



Build the project:



```powershell

.\\gradlew.bat build

```



Run the application:



```powershell

.\\gradlew.bat run

```
